# Custom Items — Crimson Cut

Interactive static launch site for the Custom Items Minecraft plugin.

## Run it

Keep the full folder intact, then open `index.html`. The background soundtrack starts only when visitors press **Sound off**, so it works with normal browser autoplay rules.

## Included

- Crimson/black cinematic visual direction
- Edited End hero art and supplied gameplay screenshots
- Scroll-driven three-stage RIFT sequence
- Audio toggle, cursor, parallax, tilt cards, reveal motion, and copyable commands
- All Modrinth calls-to-action point to `https://modrinth.com/plugin/custom-items-`
